## A color I changed snapped back

A [binding](/docs/web-app/shadcn/role-bindings) tracks the system, so it moves when the seed, variant, or contrast changes. If you need a color to stay put, [pin it with an override](/docs/web-app/shadcn/role-overrides) instead.

## An edit didn't carry to the other mode

Some controls are per mode by design: contrast, surfaces, bindings, and overrides. Switch modes with `D` and make the matching change there. See [Light & dark](/docs/web-app/light-dark).

## The hue control is off

Your seed is close to grey, so there's no hue to adjust. See [Limitations](/docs/reference/limitations).

## A contrast pair is flagged

Tonex reports contrast but doesn't force it — a flag is information, not a block. Raise the [contrast](/docs/key-concepts/contrast) level, or pin the affected role to a value that passes.

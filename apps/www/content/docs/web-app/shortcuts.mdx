title: Shortcuts
description: Keyboard shortcuts for the editor.
---

The editor is driven by single-key shortcuts. Open the command menu to browse them all, or use the keys directly.

## Command menu

Press <Kbd>⌘K</Kbd> to open the command menu, <Kbd>↑</Kbd> <Kbd>↓</Kbd> to navigate and <Kbd>Enter</Kbd> to activate. It lists the page tabs, the actions below, and links.

## Actions

| Key | Action |
|-----|--------|
| <Kbd>E</Kbd> | Open Export |
| <Kbd>E</Kbd> then <Kbd>C</Kbd> | Quick Copy |
| <Kbd>A</Kbd> | Check Contrast |
| <Kbd>S</Kbd> | Settings |
| <Kbd>H</Kbd> | Help |
| <Kbd>D</Kbd> | Toggle light / dark mode |
| <Kbd>⌘L</Kbd> | Lock / unlock the seed |
| <Kbd>C</Kbd> | Copy the export content (in the Export view) |

## Navigation

Press a number key to jump to that page tab — <Kbd>1</Kbd> for the first tab, <Kbd>2</Kbd> for the second, and so on.

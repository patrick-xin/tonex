The editor is driven by single-key shortcuts. Open the command menu to browse them all, or use the keys directly.

## Command menu

Press `⌘K` (`Ctrl+K`) to open the command menu. Inside it, use `↑` `↓` to navigate and `Enter` to activate. It lists the page tabs, the actions below, and links.

## Actions

| Key | Action |
|-----|--------|
| `E` | Open Export |
| `E` then `C` | Quick Copy |
| `A` | Check Contrast |
| `S` | Settings |
| `H` | Help |
| `D` | Toggle light / dark mode |
| `⌘L` | Lock / unlock the seed |
| `C` | Copy the export content (in the Export view) |

## Navigation

Press a number key to jump to that page tab — `1` for the first tab, `2` for the second, and so on.

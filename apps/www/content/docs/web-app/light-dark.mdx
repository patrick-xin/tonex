---
title: Light & Dark Mode
description: Both modes are built at once; you edit one at a time.
---

Tonex builds light and dark together from the same source. You edit one mode at a time, and the engine keeps the other coherent. Toggle the active mode with <Kbd>D</Kbd>.

Some settings apply to both modes at once; others only to the mode you're editing.

| Setting | Scope |
| --- | --- |
| Seed color | Shared |
| Scheme variant | Shared |
| Custom colors | Shared |
| Palette overrides | Shared |
| CMF second source | Shared |
| Chart settings | Shared |
| Contrast level | Per-mode |
| Surface adjustment (Tint / Desaturate, incl. tint neutral palette) | Per-mode |
| Tint text accent | Per-mode |
| Role bindings | Per-mode |
| Color overrides | Per-mode |

Change a **shared** setting and both modes update together. The **per-mode** split lets you push contrast harder in dark mode, or tint dark surfaces more than light ones, without disturbing the other mode.

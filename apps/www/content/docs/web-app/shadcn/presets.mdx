---
title: Binding Presets
description: Five binding presets, each a different surface style for shadcn.
---

A binding preset is a starting set of [role bindings](/docs/web-app/shadcn/role-bindings) — a decision about which generated color each shadcn role points at. Tonex ships five, each giving the interface a different surface style. Picking one sets the defaults; you can still adjust any binding afterward.

The presets differ mainly in how surfaces relate to each other. For example:

- **Clean** — cards sit on the same color as the background, for a level, minimal look.
- **Layered** — popovers and raised elements bind to a lower container surface, so they read as lifted off the page.

Choose the preset that matches the depth and separation you want, then fine-tune individual roles from there.

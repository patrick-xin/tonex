---
title: Installation
description: Run Tonex with npx, or add the core package to your project.
---

The CLI needs no install. Run it with `npx`:

```bash
npx tonex generate --seed "#6A9CFF" > globals.css
```

`npx` fetches and runs the latest version, which is convenient for one-off generation and for agents.

## Adding it to a project

To pin a version or call the engine from your own code, add the core package:

```package-install
npm install @tonex/core
```

`@tonex/core` is the engine the CLI and the web app both share. It's open source, so you can build on it directly.

## Requirements

Requires a current Node.js runtime.
